# 지식과 성장 지도

이 프로젝트는 개인 지식을 정리하고, 설명·검증·적용하는 능력을 기르며, 그 결과를 블로그로 공유하는 장기 프로젝트다. GitHub를 지식 원본과 변경 이력의 기준으로 삼고 [티스토리](https://inspire12.tistory.com)는 독자에게 전달하는 발행 채널로 사용한다.

## 학습 흐름

질문 수집 → 내 말로 지식 노트 작성 → 근거 확인·실험 → 퀴즈로 회상 → 면접으로 설명·판단 → 블로그 초안 → 복습·수정.

한 번에 한 주제를 진행한다. 모든 주제를 글로 발행할 필요는 없으며, 퀴즈 오답과 설명 중 막힌 지점은 다음 학습 질문으로 돌린다. 문서를 작성했다는 이유만으로 숙련도를 올리지 않는다.

## 첫 학습 지도

아래는 기존 자료를 바탕으로 정한 시작점이며 전체 지식 목록이나 숙련도 평가가 아니다. 관심 분야는 계속 추가한다.

| 주제 | 기존 자료 | 다음 증거 | 현재 상태 |
| --- | --- | --- | --- |
| GraphQL과 API 설계 | [실행 예제](../examples/rest-graphql-nestjs/README.md), 블로그 연재 | 요청 처리 흐름 설명, 재현 결과, 설계 대안 비교 | 자료 있음·역량 진단 전 |
| 운영·성능·장애 분석 | [블로그 모니터링 글](https://inspire12.tistory.com/490) | 외부 API 지연 재현, 관측 지표, 개선 전후 비교 | 경험 글 있음·실험 전 |
| AI 백엔드 | [기획](ai-backend/README.md), [로드맵](ai-backend/ROADMAP.md) | 주문·환불 도우미의 권한·중복 실행 검증 | 기획·초안 단계 |
| 기타 지식 | 앞으로 기존 글과 메모에서 수집 | 질문과 출처를 주제별로 분류 | 미정리 |

## 자료 위치와 사용법

- `docs/<주제>/`: 지식 노트, 설계 결정, 실험 기록, 블로그 초안. 기존 `ai-backend/` 문서도 이 구조 안에서 유지한다.
- [노트 양식](templates/knowledge-note.md): 새 주제를 시작할 때 복사한다.
- [퀴즈](practice/quiz.md): 먼저 답한 뒤 근거를 확인한다.
- [면접 연습](practice/interview.md): 한 질문씩 답하고 꼬리 질문으로 깊이를 확인한다.
- [학습 기록](practice/log.md): 실제 답변·피드백·재도전 결과를 남긴다.
- [블로그 개선 계획](blog/README.md): 기존 글과 실험·후속 글을 연결한다.
- `examples/`: 실행 가능한 검증 코드. `output/diagrams/`: SVG 원본과 PNG.

## 성장 판단

주제별로 미진단 → 도움 없이 설명 → 조건을 바꿔 적용 → 재현·검증의 증거를 남긴다. 이 순서는 내부 기록 기준이며 채용 수준을 판정하는 점수가 아니다. 부족했던 답변도 보존하고 수정 이유를 기록한다.

첫 회차는 GraphQL 퀴즈 3문제와 면접 1문제로 시작한다. 이후 오답 하나를 노트로 정리하고 작은 실험으로 확인한다. 복습 간격은 우선 다음 날·일주일 뒤로 시도하되 실제 일정과 오답에 맞춘다. 예약된 자동화는 없다.

다음 작업: 기존 블로그 글 목록 수집 → 주제별 연결 → GraphQL 첫 진단 → 부족한 지식 보완 → 기존 글 한 편의 근거·한계·예제 보강.
