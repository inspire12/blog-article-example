# AI 시대 백엔드 개발자 학습·블로그 기획

작성일: 2026-10-23 (Asia/Seoul)

## 목적

기존 백엔드 경험을 바탕으로 AI를 활용해 개발하고, AI 기능을 신뢰할 수 있는 서비스로 만드는 역량을 기른다. 모델 연구직 전환보다 서비스 구현과 운영에 초점을 둔다.

## 기술 우선순위

| 순위 | 기술 | 목표 |
| --- | --- | --- |
| 1 | AI를 활용한 개발과 검증 | 작업 분해, 요구사항·제약·완료 조건 전달, 생성 코드 테스트·리뷰·디버깅 |
| 2 | LLM API 연동과 도구 호출 | 구조화된 JSON, 스키마 검증, 스트리밍, 기존 API 연결 |
| 3 | AI 품질 평가와 운영 | 평가셋, 모델·프롬프트 변경 전후 성공률·지연·비용 비교 |
| 4 | 검색과 데이터 설계 | RAG, 키워드·벡터 혼합 검색, 최신화, 사용자별 조회 권한 |
| 5 | 신뢰성·보안 설계 | 타임아웃, 재시도, 멱등성, 최소 권한, 감사 로그, 승인 절차 |

학습은 상위 세 가지를 중심으로 진행하며, 보안과 신뢰성은 프로젝트의 기본 요구사항으로 포함한다. 모델 직접 학습, GPU 인프라, 여러 프레임워크 섭렵, 복잡한 멀티 에이전트는 필요가 생겼을 때 검토한다.

## 현재 상태와 다음 작업

- 기술 우선순위, 8주 로드맵, 주문·환불 도우미 범위와 블로그 초안을 정리했다.
- AI 프로젝트 구현과 블로그 발행은 아직 진행하지 않았다.
- 프로젝트는 익숙한 백엔드 스택으로 구현한다. 구체적인 스택과 모델 공급자는 미정이다.
- 기존 저장소의 NestJS REST/GraphQL 예제와는 별도의 기획 문서다.
- 다음 작업: 블로그 문체·분량 검토 → 필요 시 별도 프로젝트 위치 결정 → 주문·환불 API 요구사항 및 첫 통합 테스트 구현.
- 다른 컴퓨터에서는 이 저장소를 clone 또는 pull한 뒤 이 문서부터 읽으면 된다.
