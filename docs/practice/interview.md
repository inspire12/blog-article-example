# 면접 연습

목표는 암기 답안보다 문제를 정의하고 근거를 들어 선택을 설명하는 능력이다. 실제로 하지 않은 업무나 측정 결과를 경험으로 포장하지 않는다.

## 첫 세션: API 설계

질문: 현재 저장소의 REST·GraphQL 예제를 동료에게 설명한다면, 요청 처리 흐름과 비즈니스 로직의 경계를 어떻게 설명하겠는가?

답변 뒤 사용할 꼬리 질문:

1. 두 방식의 차이를 보여주는 코드 위치는 어디인가?
2. 작성자·댓글을 함께 조회해야 한다면 어떤 설계를 검토하겠는가?
3. 그 설계에서 성능 문제가 생겼는지 무엇으로 확인하겠는가?
4. 다른 방식을 선택할 조건과 현재 예제가 검증하지 못하는 부분은 무엇인가?

후속 세션 후보: 외부 API 지연 장애 분석, 환불 도구 호출의 권한·멱등성 설계.

## 진행 요청

```text
면접관 역할로 위 주제에서 한 질문씩 해줘. 먼저 내 답변을 기다려줘.
내 답변에 근거한 꼬리 질문을 하고, 질문마다 모범답안을 바로 공개하지 마.
3~5개 질문이 끝나면 정확성, 근거, 대안 비교, 설명 명확성으로 피드백해줘.
내가 언급하지 않은 경험을 만들지 말고 가상 설계와 실제 경험을 구분해줘.
실제 답변의 핵심, 부족한 조건, 보완 질문을 학습 기록에 남겨줘.
```

평가에는 답변의 구체적인 문장과 근거를 연결한다. 채용 합격 여부나 경력 수준은 단정하지 않는다.
