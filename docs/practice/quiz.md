# 퀴즈: 첫 진단

상태: 문제 초안. 아직 응시·채점하지 않았다. 먼저 자료 없이 답하고, 답변 후 저장소 코드와 공식 자료로 확인한다. 답안을 먼저 읽고 따라 쓴 결과는 회상 성공으로 기록하지 않는다.

## 진행 요청

```text
퀴즈 파일에서 아직 풀지 않은 문제를 한 번에 하나씩 내줘.
답이나 힌트를 먼저 주지 말고 내 답변을 기다려줘.
답변 뒤 맞는 부분, 빠진 조건, 잘못된 부분을 근거와 함께 설명해줘.
저장소 자료만으로 판정할 수 없으면 공식 자료를 확인하거나 판정을 보류해줘.
실제 답변과 피드백을 학습 기록에 남기고, 같은 개념의 변형 문제를 내줘.
```

기록 기준: 0=미응답·핵심 오해, 1=부분 설명, 2=핵심 설명과 근거 제시, 3=적용 조건·반례까지 설명. 문항별 누락 조건을 함께 적으며 점수만으로 숙련도를 단정하지 않는다.
