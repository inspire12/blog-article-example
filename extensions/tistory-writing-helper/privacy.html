티스토리 글쓰기 도우미 개인정보 처리방침

시행일: 2026년 11월 19일 · 제공자: inspire12

티스토리 글쓰기 도우미는 사용자가 복사하거나 입력한 표를 티스토리 편집기에 맞는 형태로 변환하는 독립적인 브라우저 확장 프로그램입니다. 티스토리 또는 OpenAI가 제공하는 공식 확장 프로그램이 아닙니다.

처리하는 정보와 목적

사용자가 티스토리 기본 모드 또는 확장 팝업에 붙여 넣거나 입력한 표·텍스트·HTML을 변환을 위해 브라우저 메모리에서 처리합니다. 자동 변환은 지원하는 티스토리 글쓰기 페이지의 편집 영역에서 이루어집니다. 작동 위치를 판단하기 위해 현재 페이지의 주소와 편집기 구조를 확인합니다. 이 정보의 이력을 기록하지 않습니다.

저장과 삭제

자동 변환의 켜짐/꺼짐 설정만 chrome.storage.local을 통해 기기에 저장합니다. 표 원문과 변환 결과를 확장 프로그램의 영구 저장소에 저장하지 않습니다. 팝업을 닫으면 팝업 입력은 초기화됩니다. 확장 프로그램을 제거하면 확장 프로그램의 설정도 제거됩니다. 복사 버튼으로 시스템 클립보드에 넣은 내용은 사용자가 다른 내용을 복사하는 등 운영체제의 기능으로 관리합니다.

외부 전송과 제3자

확장 프로그램은 표 내용, 페이지 주소 또는 설정을 개발자 서버나 분석 서비스로 전송하지 않습니다. 광고·추적·분석 SDK를 사용하지 않으며 사용자 정보를 판매하거나 제3자에게 제공하지 않습니다. 티스토리 편집기에 삽입된 글은 티스토리의 저장·자동저장 기능과 개인정보 처리방침에 따라 처리됩니다. 사용자가 외부 링크를 열거나 이미지가 포함된 HTML을 처리하면 브라우저 또는 해당 웹사이트에서 관련 리소스에 대한 요청이 발생할 수 있습니다. 확장 프로그램은 해당 외부 서비스의 데이터를 별도로 수집하지 않습니다.

권한

  • clipboardWrite: 사용자가 복사 버튼을 누를 때 변환한 표 또는 HTML을 시스템 클립보드에 씁니다. 클립보드를 백그라운드에서 계속 읽지 않습니다.
  • storage: 자동 변환 옵션을 기기에 저장합니다.
  • 티스토리 관리자 페이지 접근: 붙여넣기 이벤트 감지와 표 삽입을 위해 사용합니다.

사용 제한과 문의

처리한 정보는 표 변환이라는 사용자 기능에만 사용하며 Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용 요건을 준수합니다. 개인정보 관련 문의와 오류 제보는 GitHub Issues로 접수할 수 있습니다. 공개 문의에 개인정보나 비공개 글 내용을 포함하지 마세요.

처리 방식이 바뀌면 이 문서의 시행일과 내용을 갱신합니다.
