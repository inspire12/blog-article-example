HTTP Header 표 복사

‘표 복사’를 누른 뒤 티스토리 기본 모드에서 붙여 넣으세요. 별도 CSS 설치는 필요하지 않습니다.

역할함께 볼 핵심 헤더
표현 선택·해석Accept, Content-Type, Accept-Language
압축Accept-Encoding, Content-Encoding
캐시·재검증Cache-Control, ETag, If-None-Match, Vary
인증Authorization, WWW-Authenticate
상태 유지Set-Cookie, Cookie
다른 출처의 응답 읽기Origin, Access-Control-*
브라우저 보안 정책Content-Security-Policy 등
이동·다운로드·부분 조회Location, Content-Disposition, Range

복사가 차단되면 ‘표 선택’을 누르고 ⌘C(Mac) 또는 Ctrl+C(Windows)로 복사하세요. 붙여 넣을 때는 일반 붙여넣기를 사용하세요.

제목 행은 굵게 표시한 일반 셀입니다. 티스토리에서 실제 헤더 셀로 인식하도록 만드는 방식은 아니며, 붙여넣기 후 색상·테두리 유지 여부를 확인해야 합니다.
